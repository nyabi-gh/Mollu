# Mollu

디스코드에서 외국어 메시지를 자동으로 번역해 원문 아래에 붙여 주는 BetterDiscord 플러그인입니다.

한국어로 번역하는 것도, 반대로 한국어를 영어나 일본어로 번역하는 것도 됩니다.

## 이런 걸 합니다

- 지정한 서버(또는 모든 서버)의 메시지를 골라 둔 언어로 번역해 원문 바로 아래에 회색 글씨로 보여 줍니다.
- 1:1 DM 과 그룹 DM 도 번역합니다. 기본은 꺼져 있고, 스위치 하나로 켭니다.
- 번역할 언어는 한국어, 영어, 일본어 등 15개 중에서 고릅니다. 이미 그 언어로 쓰인 메시지는 번역하지 않습니다.
- **자동 모드**는 화면에 보이는 메시지를 알아서 번역합니다. **수동 모드**는 메시지 아래에 `번역` 버튼만 띄우고, 누른 것만 번역합니다.
- 한 번 번역한 문장은 저장해 두고 다시 쓰므로, 같은 말이 반복돼도 요금이 더 들지 않습니다.
- **내가 보내는 메시지**를 번역해서 보낼 수도 있습니다. 한국어로 쓰면 영어로 바뀌어 나갑니다. 기본은 꺼져 있습니다.
- 자주 켜고 끄는 기능은 단축키로 바로 전환됩니다.
- 새 버전이 나오면 디스코드 안에서 알아서 갱신됩니다.

## 설치

플러그인은 파일 하나입니다. 따로 설치할 프로그램은 없습니다.

1. `dist/Mollu.plugin.js` 파일을 다운로드합니다.
2. BetterDiscord 설정 → Plugins → **Open Plugins Folder** 를 눌러 열리는 폴더에 넣습니다.
3. 플러그인 목록에서 **Mollu** 를 켭니다.

폴더를 직접 찾으려면:

- Windows: `%AppData%\BetterDiscord\plugins`
- macOS: `~/Library/Application Support/BetterDiscord/plugins`
- Linux: `~/.config/BetterDiscord/plugins`

BetterDiscord는 1.14.0 이상이 필요합니다.

## 처음 설정

번역은 외부 번역 서비스를 쓰기 때문에 **API 키를 발급받아 넣어야** 합니다. 세 곳 중에 고르면 됩니다.

| 서비스 | 요금 | 발급처 |
| --- | --- | --- |
| **DeepL** | 매달 50만 자까지 무료 | [deepl.com/pro-api](https://www.deepl.com/pro-api) |
| **Google Gemini** | 무료 사용량 있음 | [aistudio.google.com](https://aistudio.google.com) |
| **DeepSeek** | 유료지만 매우 저렴 | [platform.deepseek.com](https://platform.deepseek.com) |

무료로 시작한다면 **DeepL** 이 가장 간단합니다. 번역 전용 서비스라 빠르고, 모델 같은 걸 고를 필요가 없습니다. 다만 번역 품질은 DeepSeek·Gemini 쪽이 낫습니다.

API키를 받았으면 플러그인 설정에서:

1. `번역 백엔드` 에서 쓸 서비스를 고릅니다.
2. `API 키` 칸에 발급받은 키를 붙여 넣습니다.
3. 번역할 서버를 정합니다. `모든 서버에서 번역` 을 켜거나, `대상 서버 ID` 에 서버 ID를 적습니다.
   - 서버 ID는 디스코드 설정 → 고급 → **개발자 모드**를 켠 뒤, 서버 아이콘을 우클릭 → **서버 ID 복사** 로 얻습니다.
   - DM 도 번역하려면 `DM 도 번역` 을 켭니다. 서버 설정과 별개라, 서버를 하나도 지정하지 않고 DM 만 번역할 수도 있습니다.

> **Google Gemini 무료 사용량으로 쓸 때 주의**: 보낸 내용이 구글의 서비스 개선에 쓰입니다. 이 플러그인은 서버에 있는 **다른 사람의 메시지**를 보내므로, 그 대화가 학습에 쓰인다는 뜻입니다. 유료 사용량에는 해당하지 않습니다.

## 단축키

| 기본값 | 하는 일 |
| --- | --- |
| `Ctrl+Shift+T` | 자동 번역 켜기 / 끄기 |
| `Ctrl+Shift+O` | 보내는 메시지 번역 켜기 / 끄기 |

설정에서 칸을 누르고 원하는 키를 누르면 그대로 바뀝니다. 지우면 단축키를 쓰지 않습니다.

## 설정

| 항목 | 설명 |
| --- | --- |
| 번역 백엔드 | 쓸 번역 서비스. 바꾸면 나머지 칸이 알아서 맞춰지고, 서비스별 키는 각각 기억합니다 |
| API 키 | 필수입니다. 없으면 아무 동작도 하지 않습니다. 한번 저장하면 뒤 4자리만 보이며, 지우려면 `-` 를 입력합니다 |
| 모든 서버에서 번역 | 켜면 참여 중인 모든 서버가 대상이 됩니다. DM 은 아래 스위치로 따로 켭니다 |
| 대상 서버 ID | 번역할 서버들. 쉼표나 띄어쓰기로 구분합니다 |
| DM 도 번역 | 위 두 설정과 무관하게 1:1 DM 과 그룹 DM 을 번역합니다. 기본은 꺼져 있습니다 |
| 번역할 언어 | 어떤 언어로 번역할지 |
| 플러그인 언어 | 설정 창과 안내 문구의 언어 |
| 번역 생략 기준 비율 | 메시지에서 이 비율 이상이 이미 번역할 언어면 건너뜁니다 |
| 번역할 최대 글자 수 | 너무 긴 메시지는 건너뜁니다. 요금이 갑자기 늘어나는 걸 막아 줍니다 |
| 동시 번역 요청 수 | 한 번에 몇 개까지 번역할지. 무료 사용량 한도에 자주 걸리면 1~2로 낮추세요 |
| 자동 번역 | 끄면 수동 모드가 됩니다. `번역` 버튼을 누른 것만 번역합니다 |
| 보내는 메시지도 번역 | 켜면 **내가 쓴 글이 번역문으로 바뀌어** 나갑니다. 상대는 원문을 볼 수 없습니다 |
| 보낼 때 번역할 언어 | 내 메시지를 어떤 언어로 바꿔 보낼지 |
| 봇 메시지도 번역 / 내 메시지도 번역 | 무엇까지 번역할지 |
| 번역 중 표시 / 번역 실패 시 표시 | 화면에 표시할지 말지 |

**고급** 항목:

| 항목 | 설명 |
| --- | --- |
| 모델 이름 | 어떤 모델로 번역할지. 고를 게 둘 이상일 때만 나옵니다. DeepSeek 은 둘, DeepL 은 없습니다 |
| API Base URL | 서비스를 고르면 자동으로 채워집니다. 건드릴 일이 거의 없습니다 |
| 자동 업데이트 | 새 버전이 나오면 알아서 받아 적용합니다. 몇 시간마다 확인합니다 |
| 업데이트 | `확인` 을 누르면 지금 바로 검사합니다 |
| 번역 캐시 | `비우기` 로 저장해 둔 번역을 모두 지웁니다. 번역이 이상하거나 서비스를 바꿨을 때 쓰세요 |
| 번역하지 않은 사유 기록 | 켜면 왜 번역하지 않았는지 기록을 남깁니다. 아무것도 안 나올 때 원인을 찾는 용도입니다 |

## 알아 두면 좋은 것

- 번역이 아예 안 보인다면 대부분 **번역할 언어와 서버의 언어가 같아서**입니다. 한국어 서버에서 번역할 언어를 한국어로 두면 번역할 게 없습니다.
- 내가 쓴 메시지는 기본적으로 번역하지 않습니다. 직접 써 보며 시험하려면 `내 메시지도 번역` 을 켜세요.
- 영어·스페인어·프랑스어처럼 알파벳을 쓰는 언어끼리는 보내기 전에 구분할 수 없어서, 문장마다 한 번은 번역 서비스에 물어봅니다. 그 결과는 저장되니 같은 문장에 두 번 요금이 들지는 않습니다.
- 번역에 실패하면 실패 표시를 눌러 다시 시도할 수 있습니다.
- 메시지를 수정하면 새 내용으로 다시 번역합니다.
- 디스코드가 크게 업데이트되면 번역이 표시되지 않을 수 있습니다. 플러그인 업데이트를 기다려 주세요.

## 개인정보

- 번역이 필요한 메시지의 **본문 텍스트**가 설정한 번역 서비스로 전송됩니다. 대상 서버가 아닌 메시지, 이미 번역할 언어인 메시지는 보내지 않습니다.
- `DM 도 번역` 을 켜면 **사적인 대화도** 다른 메시지와 똑같이 전송됩니다. 원치 않으면 꺼 두세요. 특히 Gemini 무료 사용량은 보낸 내용이 학습에 쓰입니다.
- `보내는 메시지도 번역` 을 켜면 **내가 쓴 글도** 보내기 직전에 같은 곳으로 전송됩니다.
- 보내기 전에 멘션·이모지·링크·코드는 다른 기호로 바꿔서 보내므로, 사용자 ID나 주소는 번역 서비스에 노출되지 않습니다.
- 번역 결과와 **API 키는 아래 파일에 그대로 저장됩니다.** 이 파일을 남에게 보내거나 화면에 띄우지 마세요.
  - Windows: `%AppData%\BetterDiscord\plugins\Mollu.config.json`
  - macOS: `~/Library/Application Support/BetterDiscord/plugins/Mollu.config.json`
  - Linux: `~/.config/BetterDiscord/plugins/Mollu.config.json`
- 저장된 걸 전부 지우려면 플러그인을 끈 뒤 이 파일을 삭제하면 됩니다.
