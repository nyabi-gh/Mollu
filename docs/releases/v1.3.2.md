## 이번 버전 (1.3.2)

- **내가 보낸 메시지 아래에 번역이 제대로 나옵니다.** `보내는 메시지도 번역` 을 켜고 보내면, 메시지 아래 번역 블록에 번역문이 아니라 내가 입력한 원문이 그대로 나왔습니다. 이제 실제로 보낸 문장을 새로 번역해서 보여 줍니다.

이미 원문이 붙어 있는 예전 메시지는 메시지 우클릭 → **Mollu로 다시 번역** 으로 고칠 수 있습니다. 설정과 API 키, 번역 캐시는 그대로 유지됩니다.

## 설치

1. 아래 **Mollu.plugin.js** 를 받습니다.
2. BetterDiscord 설정 → Plugins → **Open Plugins Folder** 에 넣습니다.
3. 플러그인 목록에서 **Mollu** 를 켭니다.

설정과 API 키 발급은 [README](https://github.com/nyabi-gh/Mollu#readme) 를 참고하세요. BetterDiscord 1.14.0 이상이 필요합니다. `Mollu.plugin.js.sig` 는 자동 업데이트가 확인하는 서명 파일이라 받지 않아도 됩니다.

## In this version (1.3.2)

- **The translation under a message you sent is a real translation.** With `Translate the messages I send` on, the block under a message you sent showed what you had typed rather than a translation. It now translates the message that actually went out.

An older message still showing what you typed can be fixed with right-click → **Translate again with Mollu**. Your settings, API keys and translation cache are untouched.

## Installing

1. Download **Mollu.plugin.js** below.
2. Drop it into BetterDiscord → Settings → Plugins → **Open Plugins Folder**.
3. Enable **Mollu** in the plugin list.

See the [README](https://github.com/nyabi-gh/Mollu/blob/main/README.en.md) for setup and where to get an API key. BetterDiscord 1.14.0 or newer is required. `Mollu.plugin.js.sig` is the signature the updater checks; there is no need to download it.
