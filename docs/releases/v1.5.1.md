## 이번 버전 (1.5.1)

- **설정 화면을 정리했습니다.** 묶음이 다섯 개로 줄었고, 처음에는 번역 서비스·번역·보내는 메시지만 펼쳐져 있습니다. 서버 ID, 단축키, 표시 옵션 같은 나머지는 접힌 **세부 설정** 과 **고급** 으로 옮겼고, 설명 문구도 짧게 줄였습니다.
- **비활성화가 거꾸로 되던 문제를 고쳤습니다.** `모든 서버에서 번역` 을 꺼 두었는데 대상 서버 ID 칸이 잠겨 있거나, 보내는 메시지 번역을 켰는데 보낼 언어를 고를 수 없던 문제입니다.

설정과 API 키, 번역 캐시는 그대로 유지됩니다.

## 설치

1. 아래 **Undertone.plugin.js** 를 받습니다.
2. BetterDiscord 설정 → Plugins → **Open Plugins Folder** 에 넣습니다.
3. 플러그인 목록에서 **Undertone** 을 켭니다.

설정과 API 키 발급은 [README](https://github.com/nyabi-gh/Undertone#readme) 를 참고하세요. BetterDiscord 1.14.0 이상이 필요합니다. `Mollu.plugin.js` 는 예전 버전의 자동 업데이트가 받는 파일이고, `.sig` 파일은 서명이라 받지 않아도 됩니다.

## In this version (1.5.1)

- **A tidier settings panel.** Five sections instead of six, and only the translation service, translation and outgoing sections start open. Server ids, shortcuts, display options and the rest moved into the folded **Fine-tuning** and **Advanced** sections, and the notes are shorter.
- **Fields are disabled the right way round.** The target server ids field could be locked while `Translate in every server` was off, and the send language could not be picked while outgoing translation was on.

Your settings, API keys and translation cache are untouched.

## Installing

1. Download **Undertone.plugin.js** below.
2. Drop it into BetterDiscord → Settings → Plugins → **Open Plugins Folder**.
3. Enable **Undertone** in the plugin list.

See the [README](https://github.com/nyabi-gh/Undertone/blob/main/README.en.md) for setup and where to get an API key. BetterDiscord 1.14.0 or newer is required. `Mollu.plugin.js` is what older versions' updater downloads, and the `.sig` files are signatures; there is no need to download them.
