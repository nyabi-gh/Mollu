## 이번 버전 (1.3.3)

- **화면에 닿기 전에 번역됩니다.** 원래는 화면 아래쪽 메시지를 미리 번역하도록 되어 있었는데, 실제로는 메시지가 화면에 들어온 뒤에야 요청이 나갔습니다. 이제 스크롤로 내려가기 전에 번역이 먼저 준비됩니다.
- **요청 한도에 걸린 뒤 더 빨리 돌아옵니다.** Gemini 무료 등급처럼 분당 요청 수가 정해진 서비스에서, 잠시 멈춘 동안 스크롤로 지나간 메시지들이 순서를 차지해 지금 보는 메시지가 늦게 번역되던 문제를 고쳤습니다.
- **스크롤과 채널 이동이 가벼워졌습니다.** 같은 번역 블록을 쓸데없이 다시 그리던 부분을 줄였습니다.

설정과 API 키, 번역 캐시는 그대로 유지됩니다.

## 설치

1. 아래 **Mollu.plugin.js** 를 받습니다.
2. BetterDiscord 설정 → Plugins → **Open Plugins Folder** 에 넣습니다.
3. 플러그인 목록에서 **Mollu** 를 켭니다.

설정과 API 키 발급은 [README](https://github.com/nyabi-gh/Mollu#readme) 를 참고하세요. BetterDiscord 1.14.0 이상이 필요합니다. `Mollu.plugin.js.sig` 는 자동 업데이트가 확인하는 서명 파일이라 받지 않아도 됩니다.

## In this version (1.3.3)

- **Messages are translated before you scroll to them.** Messages below the fold were meant to be translated ahead of time, but in practice a request only went out once the message was already on screen. Translations are now ready before you get there.
- **Faster recovery from a rate limit.** With a service that caps requests per minute, such as Gemini's free tier, messages scrolled past during a pause took their turn ahead of the ones on screen. They no longer do.
- **Lighter scrolling and channel switching.** Translation blocks are no longer redrawn when nothing in them changed.

Your settings, API keys and translation cache are untouched.

## Installing

1. Download **Mollu.plugin.js** below.
2. Drop it into BetterDiscord → Settings → Plugins → **Open Plugins Folder**.
3. Enable **Mollu** in the plugin list.

See the [README](https://github.com/nyabi-gh/Mollu/blob/main/README.en.md) for setup and where to get an API key. BetterDiscord 1.14.0 or newer is required. `Mollu.plugin.js.sig` is the signature the updater checks; there is no need to download it.
