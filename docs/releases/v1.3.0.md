## 이번 버전 (1.3.0)

- **OpenAI 와 Claude 로도 번역할 수 있습니다.** 번역 백엔드에 OpenAI(기본 `gpt-6-luna`, 추론 끔)와 Anthropic Claude(기본 `claude-haiku-4-5`)가 추가됐습니다. 지원 백엔드는 Gemini · DeepSeek · OpenAI · Claude · DeepL 다섯 가지입니다. Gemma 지원은 빠졌고, Gemini 는 3.1 이후 모델만 지원합니다.
- **Gemini 에서 긴 메시지가 "번역 중" 뒤에 사라지던 문제를 고쳤습니다.** Gemini 3.1 은 추론을 끌 수 없어 긴 메시지는 추론만 하다 답이 잘렸습니다. 이제 추론을 가장 낮게 요청하고, 잘리면 한도를 넉넉히 늘려 한 번 더 요청합니다.
- **무료 사용량 한도와 과부하를 기다려 줍니다.** Gemini 무료 사용량은 분당 15회라 금방 막히고, 붐빌 때는 503 을 돌려줍니다. 이제 과부하는 실패로 표시하지 않고 잠시 기다렸다 다시 시도하며, 한도가 분당 몇 회인지 알려 주면 그 간격에 맞춰 요청을 나눠 보냅니다.
- **서버와 채널을 우클릭 메뉴에서 켜고 끕니다.** 서버 아이콘 우클릭 → **Mollu로 번역** 으로 대상 서버를 정하고, 채널 우클릭으로 그 채널만 뺄 수 있습니다. 개발자 모드로 서버 ID 를 찾을 필요가 없습니다.
- **번역문에 서식이 보이고, 스포일러는 가려 둡니다.** 굵게 · 기울임 · 취소선 · 제목 · 인용 · 링크가 기호 대신 서식으로 보입니다. 스포일러는 번역하되 누르기 전까지 가려 둡니다.
- **보내는 메시지의 순서가 바뀌지 않습니다.** 번역 중인 메시지 뒤에 보낸 메시지가 먼저 올라가던 문제를 고쳤습니다. 번역문이 2000자를 넘으면 원문을 보내고, 번역이 10초 넘게 걸리면 원문을 보냅니다.
- **API 키가 틀리거나 잔액이 없으면 바로 알려 줍니다.** 전에는 아무 표시 없이 번역만 멈췄습니다. 이제 한 번 알리고 설정을 고칠 때까지 요청을 멈추며, 설정의 **테스트** 버튼으로 연결을 확인할 수 있습니다. 번역에 실패하면 메시지 아래에 이유가 항상 표시됩니다.
- **업데이트는 서명을 확인하고, 설치 전에 물어봅니다.** 다음 버전부터는 배포자의 서명이 맞는 파일만, 설치할지 물어본 뒤 설치합니다.
- 설정 화면을 여섯 묶음(번역 서비스 · 번역할 곳 · 받는 메시지 · 보내는 메시지 · 표시 · 고급)으로 나눴습니다.
- 일본어와 중국어를 가나로 구분합니다. 영어 등 라틴 문자 언어는 그 언어로 쓴 게 분명한 메시지를 보내지 않아 요금이 줄어듭니다.
- 한글 입력 상태나 Option 키를 누른 상태에서도 단축키가 동작합니다.
- 같은 문장이 여러 번 있을 때 화면에 보이는 메시지가 번역되지 않고 남던 문제를 고쳤습니다.

설정과 API 키, 번역 캐시는 그대로 유지됩니다. 이번 버전은 예전 업데이트 방식으로 설치되고, 서명 확인은 다음 버전부터 적용됩니다.

## 설치

1. 아래 **Mollu.plugin.js** 를 받습니다.
2. BetterDiscord 설정 → Plugins → **Open Plugins Folder** 에 넣습니다.
3. 플러그인 목록에서 **Mollu** 를 켭니다.

설정과 API 키 발급은 [README](https://github.com/nyabi-gh/Mollu#readme) 를 참고하세요. BetterDiscord 1.14.0 이상이 필요합니다. `Mollu.plugin.js.sig` 는 자동 업데이트가 확인하는 서명 파일이라 받지 않아도 됩니다.

## In this version (1.3.0)

- **OpenAI and Claude can translate too.** OpenAI (`gpt-6-luna` by default, reasoning off) and Anthropic Claude (`claude-haiku-4-5` by default) join the backends, which are now Gemini, DeepSeek, OpenAI, Claude and DeepL. Gemma is no longer supported, and Gemini from 3.1 on.
- **Fixed long messages vanishing after "Translating…" on Gemini.** Gemini 3.1 cannot stop reasoning, and a long message spent its whole budget on it. Reasoning is now asked for at its least, and a cut-off answer is asked for again with room to spare.
- **Free-tier limits and overload are waited out.** Gemini's free tier allows 15 requests a minute and answers 503 when it is busy. Overload is no longer shown as a failure; the plugin waits and tries again, and once the backend names its per-minute limit, requests are spread to stay under it.
- **Servers and channels are switched from their right-click menus.** Right-click a server icon → **Translate with Mollu**, or a channel to leave just that one out. Developer Mode is no longer needed.
- **Translations show their formatting, and spoilers stay hidden.** Bold, italics, strikethrough, headings, quotes and links render instead of their markers. A spoiler is translated but covered until clicked.
- **Messages you send keep their order.** A message sent after one still being translated no longer overtakes it. A translation over 2000 characters, or one taking more than 10 seconds, sends the original instead.
- **A refused key or an empty balance is reported at once.** Translation used to stop without a word. It now says so once and pauses until the settings change, and the **Test** button checks the connection. A failed translation always shows its reason under the message.
- **Updates are signature-checked and asked about.** From the next version on, only a file carrying the publisher's signature is offered, and it installs only when you agree.
- The settings are grouped into six sections: translation service, where to translate, messages I receive, messages I send, display and advanced.
- Japanese and Chinese are told apart by their kana. For English and other Latin-alphabet targets, a message clearly already in the language is no longer sent, which saves cost.
- Shortcuts work with a Hangul input source or with Option held.
- Fixed a repeated line staying untranslated on screen.

Your settings, API keys and translation cache are untouched. This version installs through the old updater; signature checks apply from the next one.

## Installing

1. Download **Mollu.plugin.js** below.
2. Drop it into BetterDiscord → Settings → Plugins → **Open Plugins Folder**.
3. Enable **Mollu** in the plugin list.

See the [README](https://github.com/nyabi-gh/Mollu/blob/main/README.en.md) for setup and where to get an API key. BetterDiscord 1.14.0 or newer is required. `Mollu.plugin.js.sig` is the signature the updater checks; there is no need to download it.
