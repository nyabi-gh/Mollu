## 이번 버전 (1.3.1)

- **메시지 우클릭으로 번역을 숨기거나 다시 받을 수 있습니다.** 메시지 우클릭 메뉴에 두 항목이 생겼습니다.
  - **Mollu 번역 보이기** 를 끄면 그 메시지의 번역만 숨깁니다. 수동 모드에서는 `번역` 버튼으로 돌아가고, 디스코드를 다시 시작하면 다시 보입니다.
  - **Mollu로 다시 번역** 은 저장된 번역을 지우고 번역 서비스에 새로 물어봅니다. 번역이 이상하게 나왔거나, 이미 번역할 언어라고 판단돼 번역이 붙지 않은 메시지에 쓰세요. 화면에 같은 문장이 여러 개 있으면 함께 바뀝니다. DeepL 은 같은 문장을 늘 똑같이 번역하므로 이 항목이 나오지 않습니다.
- 번역 캐시 설정의 안내를 고쳤습니다. 번역 하나가 이상할 때는 캐시 전체를 비우지 않아도 되고, 서비스나 모델을 바꿀 때도 비울 필요가 없습니다.

설정과 API 키, 번역 캐시는 그대로 유지됩니다. 1.3.0 에서 올라오는 경우, 이번 업데이트가 서명을 확인하고 설치할지 물어보는 첫 업데이트입니다.

## 설치

1. 아래 **Mollu.plugin.js** 를 받습니다.
2. BetterDiscord 설정 → Plugins → **Open Plugins Folder** 에 넣습니다.
3. 플러그인 목록에서 **Mollu** 를 켭니다.

설정과 API 키 발급은 [README](https://github.com/nyabi-gh/Mollu#readme) 를 참고하세요. BetterDiscord 1.14.0 이상이 필요합니다. `Mollu.plugin.js.sig` 는 자동 업데이트가 확인하는 서명 파일이라 받지 않아도 됩니다.

## In this version (1.3.1)

- **Hide a translation, or ask for it again, from a message's right-click menu.** A message's context menu has two new items.
  - Switching off **Show Mollu translation** hides that message's translation. In manual mode the `Translate` button comes back, and hidden translations show again when Discord restarts.
  - **Translate again with Mollu** drops the saved translation and asks the service afresh. Use it on a translation that came out wrong, or on a message that got none because the service judged it already in your language. Every copy of the same sentence on screen changes with it. DeepL translates the same text the same way every time, so it does not offer this.
- The translation cache setting says what it is for now: one wrong translation no longer calls for clearing the whole cache, and neither does switching services or models.

Your settings, API keys and translation cache are untouched. Coming from 1.3.0, this is the first update that is signature-checked and asked about before it installs.

## Installing

1. Download **Mollu.plugin.js** below.
2. Drop it into BetterDiscord → Settings → Plugins → **Open Plugins Folder**.
3. Enable **Mollu** in the plugin list.

See the [README](https://github.com/nyabi-gh/Mollu/blob/main/README.en.md) for setup and where to get an API key. BetterDiscord 1.14.0 or newer is required. `Mollu.plugin.js.sig` is the signature the updater checks; there is no need to download it.
