## 이번 버전 (1.4.0)

- **모델 목록을 최신으로 바꿨습니다.** 각 서비스의 최신 모델 중 번역에 알맞은 빠르고 저렴한 모델과 중간 단계 모델만 남겼습니다.
  - Claude: `claude-haiku-5-5` (기본), `claude-sonnet-5-5`
  - OpenAI: `gpt-6-luna` (기본), `gpt-6.1-sol`
  - Gemini: `gemini-3.5-flash-lite` (기본), `gemini-3.8-flash`
  - DeepSeek: `deepseek-flash` (기본), `deepseek-v4-pro`
- **번역에 과한 최상위 모델은 목록에서 뺐습니다.** Claude Opus 와 GPT-6 Astra 가 빠졌습니다. 이미 쓰고 있었다면 직접 입력한 모델로 그대로 계속 쓸 수 있습니다.
- **DeepSeek 의 `deepseek-v4-flash` 는 `deepseek-flash` 로 자동으로 바뀝니다.** DeepSeek 이 V4 Flash 를 은퇴시키고 새 이름으로 후속 모델을 제공하기 때문입니다.

설정과 API 키, 번역 캐시는 그대로 유지됩니다. 기본 모델을 쓰던 경우에도 저장된 모델은 바뀌지 않으니, 새 모델을 쓰려면 설정에서 골라 주세요.

## 설치

1. 아래 **Mollu.plugin.js** 를 받습니다.
2. BetterDiscord 설정 → Plugins → **Open Plugins Folder** 에 넣습니다.
3. 플러그인 목록에서 **Mollu** 를 켭니다.

설정과 API 키 발급은 [README](https://github.com/nyabi-gh/Mollu#readme) 를 참고하세요. BetterDiscord 1.14.0 이상이 필요합니다. `Mollu.plugin.js.sig` 는 자동 업데이트가 확인하는 서명 파일이라 받지 않아도 됩니다.

## In this version (1.4.0)

- **Up-to-date model lists.** Each service now offers its current fast, cheap model plus one mid tier, the ones that suit translation.
  - Claude: `claude-haiku-5-5` (default), `claude-sonnet-5-5`
  - OpenAI: `gpt-6-luna` (default), `gpt-6.1-sol`
  - Gemini: `gemini-3.5-flash-lite` (default), `gemini-3.8-flash`
  - DeepSeek: `deepseek-flash` (default), `deepseek-v4-pro`
- **Flagship models are off the list.** Claude Opus and GPT-6 Astra are more than a translation needs. If you already use one, it keeps working as a typed-in model.
- **DeepSeek's `deepseek-v4-flash` becomes `deepseek-flash` on its own.** DeepSeek retired V4 Flash and serves its successor under the new name.

Your settings, API keys and translation cache are untouched. A model you already saved stays as it is, so pick a new one in the settings to switch.

## Installing

1. Download **Mollu.plugin.js** below.
2. Drop it into BetterDiscord → Settings → Plugins → **Open Plugins Folder**.
3. Enable **Mollu** in the plugin list.

See the [README](https://github.com/nyabi-gh/Mollu/blob/main/README.en.md) for setup and where to get an API key. BetterDiscord 1.14.0 or newer is required. `Mollu.plugin.js.sig` is the signature the updater checks; there is no need to download it.
