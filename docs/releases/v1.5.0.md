## 이번 버전 (1.5.0)

- **Mollu 가 Undertone 으로 이름을 바꿨습니다.** 번역이 원문 아래(under)에 붙고, 말투(tone)를 살려 번역한다는 뜻입니다.
- Mollu 를 쓰고 있었다면 평소처럼 업데이트를 받으면 됩니다. 업데이트가 끝나면 Undertone 이 설치되어 켜지고, Mollu 파일은 지워집니다.
- 설정과 API 키, 번역 캐시는 그대로 옮겨집니다.
- 우클릭 메뉴는 이제 **Undertone으로 번역** 입니다.

## 설치

1. 아래 **Undertone.plugin.js** 를 받습니다.
2. BetterDiscord 설정 → Plugins → **Open Plugins Folder** 에 넣습니다.
3. 플러그인 목록에서 **Undertone** 을 켭니다.

Mollu 를 직접 지우고 Undertone 을 새로 넣어도 설정은 옮겨집니다. `Mollu.plugin.js` 는 예전 버전의 자동 업데이트가 받는 파일이라 새로 설치할 때는 필요 없습니다. 설정과 API 키 발급은 [README](https://github.com/nyabi-gh/Undertone#readme) 를 참고하세요. BetterDiscord 1.14.0 이상이 필요합니다. `.sig` 파일은 자동 업데이트가 확인하는 서명이라 받지 않아도 됩니다.

## In this version (1.5.0)

- **Mollu is now Undertone.** The translation sits under the original, and keeps its tone.
- If you used Mollu, take the update as usual. Once it lands, Undertone is installed and turned on, and the Mollu file is removed.
- Your settings, API keys and translation cache come along.
- The right-click menu now reads **Translate with Undertone**.

## Installing

1. Download **Undertone.plugin.js** below.
2. Drop it into BetterDiscord → Settings → Plugins → **Open Plugins Folder**.
3. Enable **Undertone** in the plugin list.

Removing Mollu yourself and dropping Undertone in also keeps your settings. `Mollu.plugin.js` is what older versions' updater downloads; a fresh install does not need it. See the [README](https://github.com/nyabi-gh/Undertone/blob/main/README.en.md) for setup and where to get an API key. BetterDiscord 1.14.0 or newer is required. The `.sig` files are the signatures the updater checks; there is no need to download them.
